> 쓰기만 하던 AI Agent, 이제 직접 만들어 봅시다! 🤖
> Plan–Act–Observe–Reflect 구조를 이해하고, 파일 처리·API 호출 같은 **실제 작업을 자동으로 수행하는 나만의 Agent**를 16주 동안 함께 만듭니다.

## 🌟 프로젝트 개요 (Project Overview)

ChatGPT, Claude 같은 AI 에이전트는 이제 일상이 되었지만, 개인이 필요한 일을 맞춤형으로 해결주지는 않습니다. 
이 프로젝트에서는 각자 **자동화하고 싶은 주제**를 정하고, Tool 실행 · Workflow · Memory · 안전 설계를 갖춘 **실행 가능한 자동화 Agent**를 처음부터 구현합니다. 중간 발표와 최종 Demo Day에서 각자의 자동화 Agent를 시연합니다.


## 🎯 프로젝트 목표 (Project Vision)

- 🧠 **Agent 구조 이해와 구현**
  - Plan → Act → Observe → Reflect 루프를 이해하고 직접 구현
- 🔧 **실행 가능한 자동화 시스템 구축**
  - Tool 실행 (Shell, File, API)
  - Task Planning & Workflow
  - Memory & Logging
  - 안전 설계 (재시도, 예외 처리)
- ⚙️ **실제 작업 자동화**
  - 파일 처리, API 호출 등 현실의 작업을 자동으로 수행하는 Agent
- 🎤 **시연과 공유**
  - 중간 발표와 최종 Demo Day에서 Agent 시연


### 📦 결과물 (Deliverables)

- ✅ 실행 가능한 자동화 Agent 코드
- ✅ Tool 실행 및 Workflow 구조를 갖춘 Agent 시스템
- ✅ 실행 로그와 Memory를 포함한 아키텍처
- ✅ README 및 설계 문서
- ✅ 시연 영상 또는 Demo 발표 자료

## 🌱 참여 안내 (How to Engage)

**참여 조건 및 우대 사항**
- 적어도 하나의 AI Agent를 구독 중이거나 구독 의향이 있을 것
- 목표 달성을 위해 열의를 갖고 노력할 것

- 우대 재능: 툴 관리, 문서 정리, 친화력
